# NoAds X15 Hybrid 4.0

Aplicație Android standalone cu două straturi:
1. filtrare DNS globală cu liste mari actualizabile;
2. serviciu opțional de Accesibilitate care apasă numai controale identificate explicit ca Skip ad / Close ad.

## Activare
1. Instalează APK-ul și actualizează listele cu filtrarea oprită.
2. Activează filtrarea globală și acceptă conexiunea VPN locală.
3. Pentru butoanele Skip/Close, activează comutatorul și apoi serviciul `NoAds X15 — Skip/Close Ads` în setările Accesibilitate.

## Confidențialitate
Serviciul de Accesibilitate nu salvează și nu transmite textul ecranului. Codul caută local doar etichete exacte și ID-uri cunoscute ale butoanelor de reclamă.

## Limite
Poate apăsa reclame YouTube doar când butonul Skip este expus accesibilității. Nu poate sări reclamele nesăribile și nu poate elimina un popup fără control Close/Skip identificabil.
